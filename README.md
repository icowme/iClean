# iClean

> 净化广告、清理垃圾数据，还有鼠标手势。

Chrome 扩展（Manifest V3）· 离线运行 · 不上传任何数据 · 无账号

![去广告面板](docs/screenshots/user-shot-ad.png)

---

## 功能

### 净化广告

- **内置规则集** —— 预装 AdGuard Base + 中文（网络规则 9.1 万条、元素隐藏规则 5.3 万条），**装完就能拦，不用自己订阅**
- **订阅 / 自定义规则** —— 粘贴规则集网址（EasyList 等）或手动写规则，支持网络拦截、`##` 元素隐藏、`$removeparam`
- **总开关 / 本站开关** —— 一键停用全部拦截；单个网站一键加白
- **从网址移除跟踪参数** —— 跳转时去掉 `utm_source`、`fbclid` 等参数
- **豁免白名单** —— 在设置页集中管理已加白的站点

### 清理垃圾数据

- **清理当前站点** —— 只清当前标签页所属站点的 Cookie / 缓存 / Storage / IndexedDB，不影响其它网站
- **一键清理全部** —— 支持时间范围（全部 / 1 小时 / 24 小时 / 7 天 / 30 天），二次确认防误触，清完自动刷新
- **清理模式** —— 快速 / 标准 / 彻底三档预设，也可逐项勾选，选择会被记住
- **白名单** —— 保护常用站点，清理当前页时自动跳过

### 鼠标手势与效率增强

- **鼠标手势** —— 按住右键划动执行后退、前进、滚动、切换标签等
- **超级拖拽** —— 拖动文字搜索、拖动链接新标签打开、拖动图片打开图片
- **书签在新标签打开** —— 当前页面保持不动，**不改写书签地址**
- **选中文字自动复制 / 鼠标悬停显示密码 / 中键打开剪贴板里的网址**

### 其它

- **禁用网页 WebRTC** —— 打开后网页拿不到你的本机地址。注意：**不是**「隐藏真实 IP」，用系统级代理时基本防不到额外东西

## 安装

1. 下载 Releases 里的 zip 并解压
2. 打开 Chrome，访问 `chrome://extensions`，右上角开启 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择解压出的文件夹

> 如需清理本地 `file://` 页面，请在扩展详情页开启「允许访问文件网址」。
